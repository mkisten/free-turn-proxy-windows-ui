# Free Turn Proxy Windows UI

Windows GUI-клиент для [`free-turn-proxy`](https://github.com/samosvalishe/free-turn-proxy), построенный по логике Android-клиента.

Приложение:

- принимает полный `WireGuard .conf`
- автоматически подменяет `Endpoint` на локальный `listen`
- сохраняет готовый локальный `.conf` для `WireGuard for Windows`
- умеет устанавливать, запускать и останавливать туннель через `wireguard.exe`
- запускает `free-turn-proxy` client вместе с `routes.ps1`
- показывает объединенный лог клиента, маршрутизации и VPN

## Возможности

- работа с `VK Calls` ссылкой прямо из интерфейса
- загрузка `client.exe` и `routes.ps1` по кнопке
- сохранение настроек в `%LOCALAPPDATA%\FreeTurnProxyWindowsClient`
- сохранение и копирование локального WireGuard-конфига
- автоматическое ожидание маршрутов и стабильного DTLS-канала перед запуском VPN
- базовая защита от типичных ошибок:
  - дублированный `obf-key`
  - дублированный `DNS`
  - конфликтующие VPN/прокси-процессы
  - расхождение имени туннеля и имени WireGuard-сервиса

## Требования

- Windows 10/11
- установленный `WireGuard for Windows`
- права администратора для:
  - `routes.ps1`
  - установки/запуска туннельного сервиса
- рабочий сервер `free-turn-proxy`
- актуальная ссылка `VK Calls`

## Быстрый старт

1. Запустите приложение:

```powershell
python app.py
```

2. Нажмите `Скачать client.exe`.
3. Нажмите `Скачать routes.ps1`.
4. Укажите:
   - адрес сервера `free-turn-proxy`
   - локальный `listen`, обычно `127.0.0.1:9000`
   - `VK Calls` ссылку
   - при необходимости `obf-profile` и `obf-key`
5. Вставьте полный серверный `WireGuard .conf`.
6. Нажмите `Сохранить локальный .conf`.
7. Нажмите `Установить туннель`.
8. Нажмите `Подключить все`.

## Как это работает

Вы вставляете обычный серверный WireGuard-конфиг, а приложение:

- берет локальный `listen`
- подменяет `Endpoint` в секции `[Peer]`
- при необходимости раскладывает `AllowedIPs = 0.0.0.0/0` в Windows-совместимый вид
- сохраняет локальную версию `.conf`
- запускает `free-turn-proxy` client
- прокидывает его вывод в `routes.ps1`
- дожидается маршрутов и DTLS
- поднимает `WireGuard`-туннель

## Кнопки

- `Открыть .conf` — загрузить WireGuard-конфиг из файла
- `Вставить` — вставить конфиг из буфера обмена
- `Очистить` — очистить поле конфига
- `Сохранить локальный .conf` — создать готовый профиль для WireGuard
- `Скопировать локальный .conf` — скопировать уже подмененный конфиг в буфер
- `Подключить` — запустить только `free-turn-proxy`
- `Отключить` — остановить `free-turn-proxy`
- `Установить туннель` — установить или обновить туннельный сервис WireGuard
- `Подключить VPN` — поднять WireGuard-туннель
- `Отключить VPN` — остановить WireGuard-туннель
- `Подключить все` — полностью запустить цепочку `free-turn-proxy + routes + VPN`
- `Статус VPN` — проверить состояние туннеля

## Сборка

```powershell
.\build.ps1
```

Готовая сборка появится в `dist\FreeTurnProxyWindowsClient\`.

## Структура данных

Приложение хранит рабочие файлы в:

```text
%LOCALAPPDATA%\FreeTurnProxyWindowsClient
```

Там лежат:

- `settings.json`
- `client.exe`
- `routes.ps1`
- сгенерированные `.conf`
- `logs\session-*.log`

## Ограничения

- это GUI-обертка над официальным клиентом `free-turn-proxy`, а не отдельная реализация протокола
- стабильность все еще зависит от:
  - сетевой политики Windows
  - драйверов VPN/фильтров
  - доступности `VK TURN`
  - корректности серверной схемы
